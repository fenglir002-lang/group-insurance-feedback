# 团险小友意见收集箱

面向营销员的横版平板问卷原型，画布尺寸为 1180 × 820 CSS 像素。

## 使用

直接用浏览器打开 `index.html`；也可在此目录运行：

```sh
python3 -m http.server 8080
```

然后访问 http://localhost:8080 。无构建步骤、无第三方运行依赖。

## 功能

- 页面外切换黄蓝纸艺、四人讨论城市轻调、双手投递三个背景版本。
- 背景、主视觉与标题分层；四人讨论使用背景和标题两层。
- 提交按钮颜色为 `#D31145`。
- 提交后提示“感谢您的反馈”，保留输入内容并置灰，按钮显示“已提交”。

## 数据说明

这是前端交互原型。反馈仅保存在当前浏览器的 localStorage，刷新后保留；不会上传服务器，也无法供管理员集中查看。正式使用需接入后端存储和身份系统。背景选择也保存在当前浏览器。

## 文件

- `index.html`：页面结构、样式和交互。
- `问卷图层/`：当前三个版本的 PNG 素材。

素材按原页面比例显示，请勿单独拉伸宽高。
